# Historical documentation

This directory preserves dated development records for provenance. It is not a
second documentation set.

- [`2026-08-development/`](2026-08-development/) contains superseded designs,
  protocol-3 measurements and profiles, and old release-readiness evidence.
- Current protocol-1 documentation starts at [`../README.md`](../README.md).

Archived documents may contain invalid measurements followed by corrections,
abandoned mechanisms, old command-line options, or incompatible wire formats.
Their original conclusions are retained where possible so rejected approaches
and measurement mistakes remain auditable. An archive link is evidence of
history, not an endorsement of a current claim.
