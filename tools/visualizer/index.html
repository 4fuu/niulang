FILE LOCATIONS

Where are the logs?

Both the client and server now create bounded JSON logs automatically. Run queqiaod logs to print their exact paths. The browser cannot scan your disk, so select one of the paths below in the system picker.

macOS LaunchAgent ~/Library/Logs/Queqiao/client.log

The standard client log, including five-second performance snapshots.

Linux user process ~/.local/state/queqiao/

Select client.log or server.log from this directory.

Production Linux server /var/log/queqiao/server.log

The shipped systemd service uses this durable server log. Copy it to a private user-readable directory before opening it in a desktop browser.

Explicit override path after --log-file

The resolved absolute path also appears in the first startup record.

Rotated history client.log.1 … client.log.5

Select the active and rotated files together for a longer timeline.

Benchmark / field soak --json / --output-dir paths

Select benchmark JSON files, or choose the entire field-soak directory.

macOS: after clicking Select log files…, press ⇧⌘G, paste ~/Library/Logs/Queqiao/client.log, then press Return. For a custom deployment, copy the path printed by queqiaod logs.
Need finer one-second per-lane profiling? 
QUEQIAO_LANE_TRACE=1 ./queqiaod client \
  --profile "$PROFILE" --telemetry-log-interval 1s

queqiaod logs client

The standard five-second aggregate telemetry needs no extra flag. QUEQIAO_LANE_TRACE=1 adds structured raw lane/scheduler records to the same runtime log.
